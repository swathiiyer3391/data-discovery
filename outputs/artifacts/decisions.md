## G1 and G3: one edge case in each function
- **G1, `extract_licence`**: When a dataset landing page displays placeholder strings such as "Unknown" or "Not specified" (common on portals like Kaggle), `extract_licence` explicitly ignores those placeholders rather than treating them as valid licences, and checks `schema.org` JSON-LD first, then licence links, then licence text while normalizing variants (e.g., "Creative Commons Attribution 4.0" -> "CC-BY-4.0"). This sets the `licence` field to `None` (`found=False`) instead of a false-positive "Unknown", ensuring missing-licence flags still trigger.
- **G3, `jsonstat_summary`**: JSON-stat 2.0 responses can encode `value` and dimension category `index` as either dense lists or sparse dicts, and may contain missing cells (`None` or omitted sparse indices) alongside `0` values and `status` flags. `jsonstat_summary` handles both list and dict forms and preserves `None` as missing rather than coercing it to `0`. This keeps non-null counts, missing counts, and summary statistics accurate without inflating zeros.
